## 🏗️ ARQUITETURA DO SISTEMA

### Princípios Arquiteturais

#### 1. Domain-Driven Design (DDD)
- **Separação por domínio de negócio** (não por tipo técnico)
- **Cada domínio é independente**
- **Linguagem ubíqua** (código reflete negócio)
- **Bounded contexts** (fronteiras claras)

#### 2. Clean Architecture
- **Dependências apontam para dentro** (domínio não conhece infraestrutura)
- **Camadas bem definidas** (Models → Repository → Service → Handlers)
- **Interfaces para abstrair dependências**
- **Testabilidade** (mock de tudo)

#### 3. SOLID Principles
- **S**ingle Responsibility - Cada arquivo/função uma responsabilidade
- **O**pen/Closed - Aberto para extensão, fechado para modificação
- **L**iskov Substitution - Interfaces substituíveis
- **I**nterface Segregation - Interfaces específicas
- **D**ependency Inversion - Depender de abstrações

## 🎨 ANATOMIA DE UM DOMÍNIO

### Camadas e Responsabilidades

```
domain/pgrs/
│
├── models/              # Entidades de negócio
│   └── pgrs.go          # Struct + Métodos de negócio
│
├── repository/          # Acesso a dados
│   ├── interfaces.go    # Contratos (interface)
│   └── pgrs_repo.go     # Implementação GORM
│
├── service/             # Lógica de negócio
│   └── pgrs_service.go  # Orquestração + Regras
│
├── handlers/            # Apresentação
│   ├── http_handler.go  # REST endpoints
│   └── ws_handler.go    # WebSocket
│
└── dto/                 # Contratos de entrada/saída
    ├── requests.go      # Input
    └── responses.go     # Output
```

### Fluxo de Dados

```
Cliente (HTTP/WS)
    ↓
Handler (Validação + Parsing)
    ↓
Service (Lógica de Negócio)
    ↓
Repository (Persistência)
    ↓
Database
```

### Exemplo Prático: Criar PGRS

```go
// 1. HANDLER recebe requisição
func (h *HTTPHandler) Create(c *gin.Context) {
    var req dto.CriarPGRSRequest
    c.ShouldBindJSON(&req)
    
    // 2. Delega para SERVICE
    pgrs, err := h.service.CriarRascunho(c.Request.Context(), &req)
    
    c.JSON(200, pgrs)
}

// 3. SERVICE aplica regras de negócio
func (s *PGRSService) CriarRascunho(ctx context.Context, req *dto.CriarPGRSRequest) (*models.PGRS, error) {
    numero := s.gerarNumeroSequencial()
    
    pgrs := &models.PGRS{
        UnidadeID: req.UnidadeID,
        Numero:    numero,
        Status:    models.StatusRascunho,
    }
    
    // 4. REPOSITORY persiste
    return s.repo.Create(ctx, pgrs)
}

// 5. REPOSITORY interage com banco
func (r *pgrsRepository) Create(ctx context.Context, pgrs *models.PGRS) (*models.PGRS, error) {
    err := r.db.WithContext(ctx).Create(pgrs).Error
    return pgrs, err
}
```

## 🔄 FLUXO PRINCIPAL: GERAÇÃO DE PGRS

### Estados do PGRS

```
RASCUNHO 
    ↓
EM_GERACAO (IA processando)
    ↓
AGUARDANDO_REVISAO (engenheiro revisa)
    ↓
    ├─→ APROVADO → PUBLICADO
    │
    └─→ EM_CORRECAO (volta para IA) ⟲
```

### Jornada Completa (Happy Path)

```
1. Engenheiro: Abre wizard de 5 passos
   ├─ Passo 1: Dados da Empresa
   ├─ Passo 2: Dados da Unidade  
   ├─ Passo 3: Inventário de Resíduos
   ├─ Passo 4: Aspectos Operacionais
   └─ Passo 5: Revisão e Confirmação
   
2. Sistema: Salva em estado RASCUNHO
   
3. Engenheiro: Clica "Gerar com IA"
   
4. Backend (WebSocket):
   ├─ Status → EM_GERACAO
   ├─ IA Auditor → Análise de compliance (15s)
   ├─ IA Redator → Memorial descritivo (20s)
   └─ Status → AGUARDANDO_REVISAO
   
5. Engenheiro: Visualiza lado a lado
   ├─ Minuta gerada (esquerda)
   ├─ Comentários (direita)
   └─ Ações: Aprovar | Solicitar Correção | Rejeitar
   
6. Engenheiro: Aprova
   
7. Sistema: 
   ├─ Status → APROVADO
   ├─ Gera DOCX formatado ABNT
   ├─ Calcula hash SHA-256
   └─ Envia email com link de download
   
8. Engenheiro: Baixa DOCX pronto
```

**Tempo total:** 10-15 minutos (vs 48h manual)

### F-PGRS-002: Geração com IA ⭐⭐⭐

**Domínio:** `internal/domain/pgrs`  
**Service:** `service/generator_service.go`  
**Agents:** `agents/auditor.go` + `agents/redator.go`  

**Endpoint:**
```
POST /api/pgrs/:id/gerar
WebSocket: { action: "pgrs.gerar", payload: { pgrs_id: 1 } }
```

**Fluxo:**
```go
// 1. HTTP recebe requisição
POST /api/pgrs/1/gerar

// 2. Handler inicia geração assíncrona
func (h *HTTPHandler) GerarComIA(c *gin.Context) {
    id := c.Param("id")
    
    // Inicia processamento em background
    go h.service.GerarComIA(ctx, id)
    
    c.JSON(202, gin.H{"message": "Geração iniciada"})
}

// 3. Service orquestra IAs
func (s *PGRSService) GerarComIA(ctx context.Context, id uint) error {
    // Busca PGRS
    pgrs := s.repo.FindByID(ctx, id)
    
    // Atualiza status
    pgrs.Status = models.StatusEmGeracao
    s.repo.Update(ctx, pgrs)
    
    // Envia progresso via WebSocket
    s.hub.SendToClient(client, Message{
        Action: "pgrs.status",
        Payload: map[string]string{
            "status": "Iniciando auditoria...",
        },
    })
    
    // Chama IA Auditor
    auditoria := s.generator.Auditar(ctx, pgrs)
    
    s.hub.SendToClient(client, Message{
        Action: "pgrs.status",
        Payload: map[string]string{
            "status": "Gerando memorial descritivo...",
        },
    })
    
    // Chama IA Redator
    relatorio := s.generator.Redigir(ctx, pgrs, auditoria)
    
    // Salva resultado
    pgrs.ResultadoAuditoria = auditoria
    pgrs.RelatorioGerado = relatorio
    pgrs.Status = models.StatusAguardandoRevisao
    s.repo.Update(ctx, pgrs)
    
    // Notifica conclusão
    s.hub.SendToClient(client, Message{
        Action: "pgrs.gerado",
        Payload: pgrs,
    })
    
    return nil
}
```

**Features:**
- ✅ Processamento assíncrono
- ✅ Feedback em tempo real via WebSocket
- ✅ Retry automático em caso de falha
- ✅ Log de todas as etapas

## 🔐 SEGURANÇA E AUTENTICAÇÃO

### JWT Authentication

**Domínio:** `internal/domain/admin`  
**Service:** `service/auth_service.go`  
**Middleware:** `internal/shared/middleware/auth.go`  

**Fluxo:**
```
1. Login: POST /api/auth/login
   ├─ Validar credenciais
   ├─ Gerar JWT token
   └─ Retornar token + refresh token

2. Requisições protegidas:
   ├─ Header: Authorization: Bearer {token}
   ├─ Middleware valida JWT
   ├─ Extrai usuário do token
   └─ Injeta no contexto
```

**Exemplo:**
```go
// Login
func (s *AuthService) Login(email, senha string) (string, error) {
    // Buscar usuário
    user := s.repo.FindByEmail(email)
    
    // Validar senha
    if !user.VerificarSenha(senha) {
        return "", errors.New("credenciais inválidas")
    }
    
    // Gerar JWT
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, jwt.MapClaims{
        "user_id": user.ID,
        "email":   user.Email,
        "role":    user.Role,
        "exp":     time.Now().Add(24 * time.Hour).Unix(),
    })
    
    return token.SignedString([]byte(os.Getenv("JWT_SECRET")))
}

// Middleware
func AuthMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        tokenString := c.GetHeader("Authorization")
        tokenString = strings.TrimPrefix(tokenString, "Bearer ")
        
        token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
            return []byte(os.Getenv("JWT_SECRET")), nil
        })
        
        if err != nil || !token.Valid {
            c.AbortWithStatusJSON(401, gin.H{"error": "Não autorizado"})
            return
        }
        
        claims := token.Claims.(jwt.MapClaims)
        c.Set("user_id", uint(claims["user_id"].(float64)))
        c.Set("user_role", claims["role"].(string))
        
        c.Next()
    }
}
```
